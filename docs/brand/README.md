# Brand assets

## Metronome + Tuner

These files are unchanged copies from the Metronome + Tuner site pack in SUBCULT
Studio (`subculture-collective/subcult-tv`,
`studio/brands/obsidian-plugin-metronome-tuner/`) at revision `159489c`. The
owner accepted the pack on October 13, 2026. The masters live in Studio. Do not
edit these copies; change the pack in Studio and copy the new files here.

Text in the lockup is converted to paths, so no font is needed. The lockup is
drawn in a dark colour for light backgrounds. The README shows it by default and
shows the one-colour mark for dark backgrounds when the reader's browser
requests a dark colour scheme. The pack has no lockup for dark backgrounds.
